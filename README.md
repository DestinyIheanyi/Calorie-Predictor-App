# 🥗 Calorie Burn Prediction App

A simple and interactive machine learning web app that predicts the number of calories burned during physical activity based on user input parameters such as age, height, weight, and duration of exercise.

Built with **Streamlit**, this app demonstrates a regression-based machine learning model trained to estimate calories burned, making it useful for fitness tracking, wellness coaching, or personal health tools.

---


---

## 📌 Features

- 📊 Predicts estimated calories burned using user inputs
- 📉 Model trained using regression algorithms
- 💻 Deployed on Streamlit Community Cloud
- 🌐 Simple and mobile-friendly UI
- 📦 Lightweight and fast

## 🧠 How the Model Works

This app uses a regression model trained on a dataset containing variables like:
- **Age**
- **Height (cm)**
- **Weight (kg)**
- **Duration of exercise (minutes)**

The model learns patterns in the data to predict the estimated **calories burned** during exercise.
